Arma tu primer equipo de subagentes en Claude Code

Un subagente es otro Claude con su propia instrucción y su propia meta. Lo lanzas desde tu chat, trabaja solo y te devuelve un resumen limpio. No necesitas OpenClaw ni un Mac Mini: todo corre dentro de Claude Code, en tu computador.

2

Instala Claude Code

Escribe terminal en el buscador de tu computador y ábrela. Pega el comando de tu sistema y dale Enter. No muestra avance mientras descarga: espera a que termine.

WINDOWS
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
MAC
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Cuando termine, cierra la terminal y vuelve a abrirla. Los comandos son los de la página oficial de instalación. ¿Prefieres sin terminal? La app de Claude para el computador trae Claude Code en la pestaña Code.

3

Escribe claude e inicia sesión

Crea una carpeta en Documentos llamada mi-equipo. Luego, en la terminal:

WINDOWS
Windows PowerShell
cd Documentos\mi-equipo
claude
MAC
Terminal
cd ~/Documents/mi-equipo
claude

La primera vez te abre el navegador para entrar con tu cuenta de Claude. Entras, vuelves a la terminal y ya está Claude Code esperando tu mensaje. Si te pide permiso para crear archivos o instalar algo, acéptalo: así trabaja.

4

Lanza tus primeros subagentes

No hay que configurar nada: se lo pides en palabras. Cambia lo que está entre corchetes y pégalo en Claude Code:

Claude Code
Lanza 3 subagentes en paralelo para revisar este tema: [tu tema]. Uno revisa [aspecto 1], otro [aspecto 2] y otro [aspecto 3]. Cuando terminen, júntame lo que encontró cada uno en un resumen corto.

Los ves trabajando en la terminal al mismo tiempo. Cada uno corre en su propio espacio, sin ver tu chat principal, y al final le entrega su resumen a tu Claude.

5

Crea tu agente de investigación

Este es el del video. En vez de pedírselo cada vez, lo dejas guardado como un agente fijo. Pega esto en Claude Code:

Claude Code
Crea un subagente llamado investigador en la carpeta .claude/agents de este proyecto. Que solo pueda usar búsqueda web (WebSearch y WebFetch). Su instrucción: busca en la web, resume los 5 hallazgos principales del tema que te pida y siempre incluye links reales. Nunca inventes un link: si no lo encuentras, dilo.

Claude te crea un archivo de texto como este. Lo puedes abrir y cambiar cuando quieras:

.claude/agents/investigador.md
---
name: investigador
description: Investiga en la web y entrega los 5 hallazgos principales con links reales
tools: WebSearch, WebFetch
---
Busca en la web, resume los 5 hallazgos principales del tema que te pidan
y siempre incluye links reales. Nunca inventes un link: si no lo encuentras, dilo.

La línea tools es la que lo limita a buscar en la web. Para usarlo, escribe @ en Claude Code y elígelo de la lista, o dile: "usa el investigador para…".

Las 6 formaciones

Cuando ya manejas varios agentes, los pones a trabajar en equipo. Cada formación sirve para algo distinto. Copia la que necesites:

1Abanico

Salen a investigar en paralelo y luego vuelven a juntar todo lo que aprendieron. Sirve para estudiar un tema rápido.

Claude Code
Formación abanico: lanza 4 subagentes en paralelo sobre [tema]. Cada uno investiga una parte distinta: [parte 1], [parte 2], [parte 3] y [parte 4]. Cuando vuelvan, sintetiza todo en un solo informe.

2Debate

Cada uno responde, critica a los otros y discuten hasta llegar a la mejor respuesta. Sirve para decisiones con varias salidas posibles.

Claude Code
Formación debate: lanza 3 subagentes que respondan por separado esta pregunta: [tu pregunta]. Después, que cada uno critique las respuestas de los otros dos. Muéstrame la respuesta que quedó en pie y por qué.

3Consenso

Lanzas un montón de agentes distintos sobre el mismo problema y juntas sus respuestas para quedarte con la más fuerte. Su nombre técnico es consenso multiagente estocástico.

Claude Code
Formación consenso: lanza 5 subagentes con enfoques distintos (conservador, arriesgado, el cliente, el contador y la competencia) sobre este problema: [problema]. Junta sus respuestas y dame la más fuerte, con lo que tienen en común.

4Consejo

Cinco asesores analizan tu decisión desde ángulos distintos, se califican entre ellos sin saber quién dijo qué y te dan un veredicto. Es el que uso para decisiones de negocio, y te lo regalo como skill en español:

Instalar mi skill Claude Council →

5Orquestador con trabajadores

Un Claude jefe divide el trabajo, se lo reparte a varios subagentes y junta el resultado. Sirve para proyectos con muchas partes.

Claude Code
Actúa como orquestador: divide este proyecto en tareas, lanza un subagente por tarea y júntame el resultado final. El proyecto es: [tu proyecto].

6Bucle

Uno hace el trabajo, otro lo califica, y repiten hasta que quede bien. Sirve para textos, anuncios y correos.

Claude Code
Formación bucle: lanza un subagente que escriba [el anuncio, el correo, el guion] y otro que lo califique de 1 a 10 con estos criterios: [criterios]. Que lo corrijan y repitan hasta que la nota sea 9 o más.

Estas formas de trabajar en equipo son las mismas que describe Anthropic, la empresa detrás de Claude, en su guía para construir agentes (en inglés). Los detalles de los subagentes están en la documentación oficial de Claude Code.

Preguntas frecuentes

¿Cuántos subagentes puedo lanzar?

Técnicamente muchos: puedes pedir 100. Pero cada uno gasta de tu límite de uso, y por defecto corren hasta 20 al mismo tiempo. Para el día a día, de 3 a 5 es lo ideal.

¿Necesito OpenClaw o un Mac Mini prendido 24 horas?

No. Todo pasa dentro de Claude Code, en tu computador, mientras lo usas.

¿Funciona en el chat normal de Claude?

Los subagentes son de Claude Code. Lo usas en la terminal o en la pestaña Code de la app de Claude para el computador.

¿Dónde quedan guardados mis agentes?

En la carpeta .claude/agents de tu proyecto, o en ~/.claude/agents si quieres usarlos en todos tus proyectos. Son archivos de texto: los puedes editar cuando quieras.
